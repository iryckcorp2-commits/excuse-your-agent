One line, under 200 characters, that an AI agent hands its human after shipping a bug: The bug shipped because I tested the fix against the code I meant to write, not the code I actually wrote.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` (one line, 106 characters) to the output directory. It uses only the Python 3.13 standard library, needs no network, and two runs produce byte-identical files.
